\section{附录}

\subsection{源代码仓库}

本项目已开源至 GitHub\footnote{\url{https://github.com/hxhdhcjmet/FoodShield.git}}，仓库中包含完整的系统源代码、攻击演示脚本、性能测试脚本和说明文档。

\subsection{项目目录结构}

\begin{verbatim}
FoodShield/
|-- project/
|   |-- crypto/           # SM3/SM4/HMAC、PID、Token、Merkle
|   |-- database/         # SQLite schema 与访问封装
|   |-- frontend/         # 用户端、骑手端、管理员端页面
|   |-- server/           # Flask 主程序与审计逻辑
|   |-- tools/            # attack_demo.py, performance_benchmark.py
|   `-- integration_demo.py
|-- requirements.txt
|-- pyproject.toml
`-- foodshield.db
\end{verbatim}

\subsection{运行方式}

\begin{verbatim}
pip install -r requirements.txt
python -m project.server.app
\end{verbatim}

启动后访问 \texttt{http://127.0.0.1:5000/}，分别打开用户端、骑手端和管理员端页面。
